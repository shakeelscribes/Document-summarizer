# 🧠 BriefMind AI
### Executive Document Intelligence • Powered by Groq LPU

BriefMind is a high-performance document summarization engine designed for speed and elegance. By leveraging **Groq's LPU (Language Processing Unit)** inference technology and **Llama 3.3 70B**, it delivers near-instant executive-level insights from long-form documents.

---

## 🚀 Features
- **Blazing Fast Inference:** Powered by Groq for sub-second text generation.
- **Intelligent Streaming:** Real-time text display with a modern active cursor effect.
- **Glassmorphic UI:** A sleek, cyber-dark aesthetic with reactive components.
- **Scalable Architecture:** Built using Streamlit for seamless deployment and performance.
- **Multi-Format Support:** Effortlessly process `.txt` and `.csv` files.

## 🛠️ Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/your-username/BriefMind.git](https://github.com/your-username/BriefMind.git)
   cd BriefMind
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Configure Environment:**
   Create a `.env` file in the root directory:
   ```env
   GROQ_API_KEY=your_actual_api_key_here
   ```

## 🏃 Quick Start
Launch the application locally:
```bash
streamlit run app.py
```
